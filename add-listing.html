Add a Listing

Turn something you found on MachineryTrader or EquipmentTrader into text you paste into GitHub

1 Paste what's already in your file

Open data/manual-listings.json in your GitHub repo and paste its whole content below. First time doing this? Leave it as [].

2 Fill in the listing

That looks like it might be a search or category page rather than one specific machine — double-check you've copied the link for the individual listing, or its link on your page won't go anywhere useful.

3 Copy the result into GitHub

This replaces the entire content of data/manual-listings.json — select all the old text in that file before pasting this in.
